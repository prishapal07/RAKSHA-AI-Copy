# RAKSHA AI — Recreated Frontend Prototype

A React + TypeScript + Vite recreation based on the screen recording supplied by the project owner.

## Run locally

1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open the extracted folder in VS Code.
4. Open Terminal in that folder and run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```
